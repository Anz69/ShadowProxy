# ЧАСТЬ A. Аудит текущего дизайна

## A1. Стек (трогать нельзя без причины)
- **Next.js 15.5** (App Router) + **React 19** + **TypeScript**
- **Tailwind CSS v4** (через `@theme`/CSS-переменные, без `tailwind.config` в старом виде)
- **GSAP 3.15 + @gsap/react** — анимации (reveal на скролле, переходы страниц)
- **@tanstack/react-query 5** — данные; **react-hook-form + zod** — формы
- **react-hot-toast** — тосты; **lucide-react** — иконки; **nextjs-toploader** — прогресс-бар навигации
- Шрифт: **Struve** (локальный .otf, веса 300–900) — единственное семейство

## A2. Текущая дизайн-система (как есть)
**Тема:** тёмная, «dark glass» (стекло с blur).

**Цвета (`globals.css :root`):**
| Токен | Значение | Роль |
|---|---|---|
| `--primary` | `#0067FF` | основной синий (CTA, акценты) |
| `--secondary` | `#3A5FFD` | вторичный синий (градиенты) |
| `--accent-blue` | `#0066FF` | дубль синего (рассинхрон ⚠ — два почти одинаковых синих) |
| `--back` / `--bg-main` | `#18191D` | фон страницы |
| `--bg-card` | `#121825` | фон карточек (вариант 1) |
| `--card` | `#0D0E11` | фон карточек (вариант 2 — ⚠ два разных «card») |
| `--body` | `#EDF6F9` | основной текст (не чисто белый) |
| `--text-gray` | `#8F9BB3` | вторичный текст |
| `--border` | `rgba(255,255,255,0.08)` | обводки |
| success / warning / error | `#2FC972` / `#FFD964` / `#E84646` | статусы |

> Замер по `globals.css` (частота хексов): чаще всего — `#ffffff`/`#fff`, затем
> голубой `#79A8FF` (свечение/акцентный текст), два синих `#0066ff`/`#0067ff`,
> `#3a5ffd`, плюс уже мелькают `#00c2ff`, `#3a8bff`, `#0052cc`, `#0044aa`. То есть
> в проекте **стихийно завёлся голубой акцент** (`#79A8FF`) — это лишний аргумент
> легализовать **один** аккуратный второй акцент вместо россыпи случайных голубых.

**Эффекты:** frosted glass (`backdrop-filter: blur(10–30px)`), тонкие градиентные обводки (`background-clip`), фирменный ease `cubic-bezier(0.16,1,0.3,1)`, премиум-«переливание» бейджей (keyframes `premium-flow`/`premium-sheen`), sheen-проблеск карточек на hover.

**Анимации (GSAP, `src/shared/anim/`):** reveal-варианты `up/fade/scale/left/right/blur/rise` через IntersectionObserver; переход между страницами crossfade+scale+blur; персистентный layout (хедер/футер не ремаунтятся).

## A3. Структура страниц (30 роутов)
**Публичные / маркетинг:**
- `/` — **главная**: hero, блок «Стандартные/Премиум прокси» (tier-карточки), «Почему выбирают нас» (7 фич-карточек), «Как работает» (4 шага), trust-блок, «API-система» (4 шага) + CTA
- `/u-api` — документация API (ключ, сниппеты curl/python/js, грид методов)
- `/packages/pc-proxy`, `/packages/mob-proxy`, `/packages/[packageId]` — страницы пакета: график трафика + генератор прокси
- `/referral` — реферальная: 3 стат-блока + таблица начислений
- `/reviews` — отзыв (форма/успех)
- `/terms`, `/privacy` — текстовые

**Приложение (после входа):**
- `/dashboard` — баланс, трафик-статы, карусель купленных пакетов, привязанные аккаунты
- `/payment` — выбор тарифа (tier-карточки) → объём трафика (TrafficInput) → итог → «Купить» → модалка оплаты
- `/payment-time` — мобильные прокси по времени (страны/оператор/время)
- `/balance` — пополнение баланса
- `/payment/confirmation` — подтверждение

**Авторизация (`/auth/*`):** login, register (+success), reset-password (+process+success), email-verification. Сплит-экран: слева glass-панель с картинкой+каруселью брендов, справа форма.

**Админка (`/admin/*`):** users, keys, servers, logs, stats, reviews, settings. Таблицы, графики, модалки.

## A4. Переиспользуемые компоненты
`shared/components/ui/`: **Card, Button, Input, Checkbox, SegmentedControl, Select, SelectWithSearch, MultiSelect, Range, Modal, Loader, Footnote, Copy**.
`shared/components/widgets/`: **Header** (+ PricesPopUp мега-меню, NotificationBell, LanguageSwitcher), **Footer**, **Continent**, **ProxyConfigurator**.

## A5. Что СЕЙЧАС не консистентно (главные боли — это и есть причина редизайна)
1. **Зоопарк поверхностей:** одновременно живут `bg-card/50`, `bg-white/10`, `bg-[#303338]`, `bg-[#2A2D35]`, `glass-card`, `glass-panel` — карточки выглядят по-разному на разных страницах.
2. **Два синих:** `#0067FF` и `#0066FF` — рассинхрон.
3. **Хардкод-хексы** разбросаны по JSX вместо токенов.
4. **Радиусы и отступы не токенизированы:** `rounded-xl / rounded-2xl / rounded-[24px]`, `16/18/20/24px` вперемешку.
5. **Часть страниц «плоские»** (старый стиль), часть — стеклянные → нет единого языка.
6. **Один шрифт на всё** (Struve) — нет пары «дисплей/текст», заголовки не выделяются.
7. **Один акцент (синий)** — не хватает второго цвета для расстановки акцентов и статусов.

> Цель редизайна: **один визуальный язык на всех 30 страницах**, единые токены (цвет/типографика/радиусы/тени/спейсинг/анимации), свежая палитра с **новым акцентным цветом**, аккуратные стеклянные поверхности и единые компоненты.

## Как этим пользоваться
1. Открой **Часть B**, поправь поля `[[...]]` (стиль, шрифты, акцент, пожелания).
2. Выбери акцент: по умолчанию **Aqua-mint `#19E3B8`** — самый аккуратный со синим на тёмном. Не уверен — оставь A, спросишь у Клода превью с 2–3 вариантами на Этапе 1.
3. Скинь Клоду промпт **+ файл лого** («вот лого»).
4. Дизайн пойдёт поэтапно (концепт → токены → страницы) — на каждом этапе сможешь править.
