Референс — brightdata.com (структура, премиальность). Поверх — точечный glass.

- **Glass** (`backdrop-filter: blur`, полупрозрачный фон): карточки прокси (главная, оплата), mega-menu каталога, модалки, центр уведомлений. Премиум-карточки — усиленный blur + glow + акцентный градиент + бейдж `PREMIUM`.
- **Плотные градиенты/тени** (как Bright Data): hero, инфо-блоки, footer, кнопки/CTA.
- Премиум всегда визуально сильнее стандарта. Hover плавный. Единая палитра/типографика.

## Реализованная архитектура (Ч.1+Ч.2, для поддержки)

**Backend**
- Модели: `Review` (1:1 user), `Notification` (type/title/body/link/readAt), `TrialIdentity` (`@@unique[provider,providerKey]`); `User.trialDiscountAvailable/reviewDiscountAvailable`.
- Миграция `20260515120000_add_reviews_notifications_trial_identity`; бэкфилл `scripts/backfill-trial-identity.js` (идемпотентный).
- Модули: `notification` (service+controller, `createOnce` антидубль), `review` (user + admin эндпоинты).
- `auth`: `GET /auth/link/:provider` + `/callback`, `POST /auth/link/telegram`, `DELETE /auth/link/:provider`. Глобально уникальный `providerAccountId`, запрет отвязки последнего способа входа.
- `getTrial`: привязка обяз. → проверка `TrialIdentity` → транзакция (trial + флаг + identity) → уведомление.
- `payments`: `computeDiscount` (lifecycle), применение в `buildAndSaveInvoice`, «сгорание» в `processPaidOrder` при `PAID`; `GET /payments/active-discount`.
- `settings.getDiscounts()` — ленивый дефолт `{trial:30,review:30}`.

**Frontend**
- `features/notifications` (bell+list, polling 60с), `features/reviews` (форма+хуки), `features/user` (`LinkedAccounts`, `useTelegramLink`, `account-link.service`), `features/payments/useActiveDiscount`.
- `TrialModal` gating, дашборд (баннер отзыва + виджет скидки + LinkedAccounts), `admin/reviews`, Telegram-иконка + колокол в `Header`.
- i18n: ru/en/zh-CN (`notifications.*`, `reviews.*`, `profile.linkedAccounts.*`, `trialModal.requireLink*`, `dashboard.discountBanner/reviewBanner.*`, `payment.discountLabel`).

**Вне скоупа итерации:** Части 3, 4, 5.3, общий редизайн до уровня Bright Data.

## Утверждённые решения (закрыто заказчиком)

1. **Авто-активация триала после привязки** — НЕ делаем молчаливую активацию. Кнопка разблокируется при наличии привязки, юзер сам выбирает тариф и жмёт «Активировать». Подтверждено: «сделано правильно». Финально.
2. **«Настройки профиля» / `/profile`** — отдельную страницу НЕ создаём. Блок «Привязанные аккаунты» остаётся в дашборде (`#linked-accounts`). Подтверждено заказчиком. Финально.

Отклонения ⚠️ в Части 2 выше — это согласованное поведение, а не недоработка.
