# Аудит production-спринтов

## Закрыто в коде

- Mobile перенесён в пользовательскую категорию Premium Mobile без изменения enum и существующих балансов; Premium Residential отображает 5 звёзд.
- ISP Netherlands ограничен кодом `NL` на backend и фиксированным выбором в UI. ISP USA скрыт от новых продаж текущим sprint-gating.
- Список результата генерации живёт только в состоянии текущей страницы и сбрасывается при refresh/выходе; сами прокси в БД не удаляются.
- Админская настройка цен охватывает активные тарифы; публичная цена рассчитывается как минимум за единицу среди пакетов и показывается с «от».
- Промокоды имеют атомарную активацию, срок, one-time/multi-use, уникальность на пользователя, историю, деактивацию и удаление.
- Страница баланса и статистика переведены на адаптивные glass-компоненты; статистика учитывает все актуальные типы.
- Mango reconcile работает отдельно от деплоя, имеет dry-run, подтверждение destructive-режима, проверку результата и не меняет site balance.
- Gateway audit не удаляет данные и не выключает сервер без явных `--execute --keep=...`; кроме портов и живого HTTPS он проверяет поступление трафика в БД, а публичный DNS отделён от внутреннего IP.
- Существующие маршруты поддержки и серверно подтверждённая роль администратора сохранены.

## Автоматическая проверка

- Prisma schema validate/generate: проходит.
- Backend production build: проходит; Jest — 17 suites / 23 tests.
- Release scripts: 4/4 теста проходят; Mango/gateway/smoke scripts также проходят `node --check`.
- Frontend production build и type-check: проходят; lint — 0 ошибок, 71 существующее предупреждение.
- ISP Netherlands, ISP USA и Residential Lite покрыты unit-тестами формата upstream, гео и ограничения ротации.
- Ранее на dev выполнен живой gateway smoke через единственную ACTIVE-ноду: ISP NL, ISP USA, Residential Lite и Mango — 4/4 успешных загрузки по 100 KB. Чтобы повторный тест не затрагивал случайный пользовательский Mango upstream, текущий smoke по умолчанию проверяет только три новых тарифа; Mango теперь включается отдельным `--include-mango` и требует выделенного тестового прокси.
- Go-тесты агента локально не запускались: Go runtime не установлен. Работоспособность развёрнутого агента подтверждена systemd health, авторизованным control-plane health и живым трафиком четырёх провайдеров.

## Внешний блокер Mango migration

Read-only preflight проверил 28 связанных с БД Mango-субаккаунтов, но Mango API вернул timeout/HTTP 522 по всем запросам. Скрипт завершился до первой мутации, поэтому трафик Mango не обнулялся и не восстанавливался. Production-операцию разрешено выполнять только после восстановления Mango API и получения полного экспорта всех Mango username, включая аккаунты вне БД сайта.
